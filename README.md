# Exercícios de Programação Orientada a Objetos em Java

Este repositório reúne diferentes cenários e exercícios desenvolvidos em Java com foco em Programação Orientada a Objetos (POO).  
O objetivo é praticar conceitos fundamentais da orientação a objetos através de exemplos práticos e organizados.

## 🚀 Conceitos trabalhados

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Construtores
- Métodos e atributos
- Organização de projetos em Java


Cada pasta representa um cenário diferente e cada um tem um README explicativo da Situação-Problema

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/marcusfonseca7/CenariosJava
```

2. Abra o projeto na IDE de sua preferência:
   - IntelliJ IDEA
   - Eclipse
   - VS Code

3. Execute a classe `Main` do cenário desejado.

## 📚 Objetivo

Praticar lógica de programação e reforçar os principais conceitos de POO em Java através de exercícios e simulações de cenários do dia a dia.
